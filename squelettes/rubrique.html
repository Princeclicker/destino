[(#REM) rubrique.html - every published section. Each section has a matching body file, included dynamically as fond=body-ID_RUBRIQUE. Dynamic includes work in this SPIP build; the usual conditional-block and B_x-if-loop forms do NOT, they report "Undefined filter ==" and echo the source into the page. body-58.html About Us GoWilds about.html body-59.html Destinations GoWilds destination.html body-60.html Tours GoWilds tour.html body-61.html Blog GoWilds blog.html body-62.html Contact GoWilds contact.html body-63.html Services services grid from rubrique 63 articles The page must sit inside a RUBRIQUES loop: this is what makes the environment id_rubrique available to #ID_RUBRIQUE below (and to the enclosed body file), so body templates can build loops for the current section. Adding a section means adding body-ID.html for its new id, otherwise the dynamic include fails. Never put square brackets inside a REM comment in this project. The lexer treats a bracket pair as a code delimiter and then echoes the whole comment into the rendered page. HTML comments are not safe either, they are echoed too, so REM is the only comment form that works here. )]
